# House Price Prediction

Проект по прогнозированию стоимости домов на основе объявлений о продаже недвижимости.

## Бизнес-задача

Помочь агентству недвижимости быстро оценивать рыночную стоимость объектов и выявлять выгодные предложения.

## Данные

- Объём: **377 185** записей
- 18 исходных признаков
- Целевая переменная: цена продажи (`target`)

Данные содержали много «грязных» полей (цена в текстовом формате, JSON-поля `homeFacts` и `schools` и др.).

## Основные этапы

### 1. Очистка и Feature Engineering
- Извлечение числовой цены из строк вида `$418,000`
- Парсинг JSON-полей (`year_built`, `lot_size` и др.)
- Извлечение среднего рейтинга школ
- Создание бинарных признаков (наличие бассейна, камина)

### 2. Моделирование

| Модель                  | R² Score |
|-------------------------|----------|
| Linear Regression       | 0.526    |
| Ridge                   | 0.527    |
| Random Forest           | 0.710    |
| Gradient Boosting       | 0.726    |
| **XGBoost**             | **0.735**|

### 3. Лучшая модель — XGBoost

| Метрика                        | Значение      |
|--------------------------------|---------------|
| R² Score                       | 0.735         |
| RMSE (log scale)               | 0.460         |
| MAE                            | $184 013      |
| Median Error                   | $4 693        |
| Median Percentage Error        | **1.7%**      |

Модель хорошо работает на объектах до $500k (ошибка 1–3%).
